# Finanzza — Guía de marca

> **Instrucción para agentes de IA:** todo contenido, diseño, interfaz, texto o componente que generes para Finanzza debe seguir este documento. Regla principal: **Finanzza no le dice al usuario qué hacer con su dinero; le ayuda a entenderlo para que decida mejor.**

---

## 1. La marca

| | |
|---|---|
| **Nombre** | Finanzza |
| **Dominio** | www.finanzza.app |
| **Categoría** | Fintech / finanzas personales y empresariales |
| **Producto** | App de control y gestión financiera |
| **Slogan** | Tu dinero. Tus decisiones. |
| **Personalidad** | Profesional, inteligente, clara, moderna, confiable, motivadora |

**Misión.** Ayudar a las personas a tomar el control de su dinero con una experiencia sencilla, visual e inteligente.

**Visión.** Ser la plataforma de referencia para pasar de *administrar* el dinero a *comprenderlo y usarlo estratégicamente*.

**Propuesta de valor.** Centralizar ingresos, gastos, ahorros, presupuestos, metas, categorías, movimientos, tendencias y reportes en una sola vista fácil de entender.

**Diferenciador.** Otras apps solo registran gastos. Finanzza cubre el ciclo completo:
**Registrar → Entender → Analizar → Decidir → Mejorar**

**No es:** un banco, ni corporativa, fría, técnica, agresiva, ostentosa, infantil o saturada.

### Tres pilares de comunicación

| Pilar | Mensaje |
|---|---|
| **Control total** | Visualiza tus ingresos, gastos y ahorros en un solo lugar. |
| **Metas claras** | Establece objetivos financieros y lleva seguimiento. |
| **Decisiones inteligentes** | Reportes y análisis para tomar mejores decisiones cada día. |

### Mensajes secundarios

Nunca desplazan al slogan principal.

- Tu aliado financiero.
- Planifica. Ahorra. Invierte. Alcanza tus metas.
- Controla tu dinero. / Entiende tus finanzas.
- Tus finanzas, en un solo lugar.
- Convierte tus números en decisiones.
- Planea mejor. Vive mejor.

### Keywords

Finanzas · Control · Claridad · Crecimiento · Inteligencia · Tecnología · Progreso · Confianza · Análisis · Decisiones · Ahorro · Metas · Independencia

## 2. Logotipo

Símbolo geométrico + wordmark "Finanzza". El símbolo combina barras de crecimiento ascendentes con la letra **F**, y funciona solo como ícono de app.

**Atributos:** geométrico, simple, escalable, tecnológico, minimalista.

**Versiones aprobadas**

- Horizontal sobre fondo oscuro (Midnight Navy) — versión principal.
- Horizontal sobre fondo claro (blanco / Light Gray).
- Símbolo aislado, en círculo o en contenedor redondeado oscuro.
- Con o sin bajada de slogan.

**Prohibido:** deformar proporciones, rotar el símbolo, cambiar colores o tipografía, agregar sombras o efectos, usarlo sobre fondos de bajo contraste.

**Ícono de app.** Símbolo verde sobre contenedor oscuro con esquinas redondeadas. Debe leerse bien en smartphone, escritorio, favicon, notificaciones y accesos directos.

|---|---|---|
| Midnight Navy | `#0D1B2A` | Fondo principal, headers, navegación, pantallas financieras |
| Deep Blue | `#1B263B` | Tarjetas, superficies secundarias, componentes UI |
| Finanzza Green | `#22C55E` | Color de marca: acciones principales, estados positivos, botones, gráficas |
| Mint | `#4ADE80` | Degradados, highlights, estados secundarios, ilustraciones |
| Light Gray | `#E5E7EB` | Fondos claros, bordes, separadores, light mode |

### Color con significado

| Color | Significa |
|---|---|
| **Verde** | Ingresos, ahorro, crecimiento, metas cumplidas |
| **Rojo** | Gastos, alertas, riesgos, excesos — uso moderado, nunca dominante |
| **Azul** | Información, datos, análisis, estados neutros |
| **Amarillo / naranja** | Advertencias, presupuestos cerca del límite |

Para categorías de gasto (donas, barras apiladas) se permite una paleta categórica más amplia, siempre sobre base oscura y con etiquetas legibles.

## 4. Tipografía

**Poppins**, en tres pesos: Regular, Medium, SemiBold.

| Nivel | Peso |
|---|---|
| Headings | SemiBold |
| Subheadings | Medium / SemiBold |
| Body | Regular |
| Labels | Medium |
| Datos financieros | SemiBold |

Las cifras importantes (saldo, totales) llevan el mayor peso visual de la pantalla.

## 5. Interfaz

### Principios de UI

1. Claridad antes que decoración.
2. Información importante primero.
3. Menos elementos, mejor organizados.
4. Gráficos solo cuando faciliten la comprensión.
5. Consistencia visual.
6. Color con propósito.

La interfaz debe responder en segundos: *¿cuánto tengo?, ¿cuánto gasté?, ¿cuánto ingresó?, ¿cuánto ahorro?, ¿en qué gasto?, ¿voy cumpliendo mis metas?*

### Dashboard

De arriba hacia abajo: **saldo total** (con variación vs. mes anterior) → evolución financiera → ingresos / gastos / ahorros → distribución por categorías → metas → movimientos recientes.

### Navegación

Barra inferior de 4 secciones: **Resumen · Transacciones · Metas · Más**.

### Visualización de datos

Líneas, barras, donas, barras de progreso, comparativas e indicadores. Cada gráfica responde una pregunta concreta; ninguna es decorativa.

### Iconografía

Estilo lineal, minimalista, geométrico y consistente (sin relleno ni detalle excesivo).
Set base: casa, gráfica de pastel, transferencias, billetera, meta, gráfica de crecimiento, tarjeta, alcancía, campana, configuración.

### Imagen y gráfica

- **Fotografía:** tranquilidad, progreso, planeación, independencia, tecnología. Evitar oficinas, trajes y clichés de dinero.
- **Ilustración:** trazo lineal geométrico, con el verde de marca como acento.
- **Evitar siempre:** riqueza ostentosa, lujo, billetes cayendo, monedas, símbolos bancarios tradicionales, interfaces saturadas.

## 6. Voz y tono

Clara, directa, inteligente, positiva, humana y responsable. Nunca prometer resultados garantizados.

**Estructura de todo mensaje: Dato → Contexto → Acción**

> "Este mes gastaste $8,420." → "Eso representa 18% más que el mes anterior." → "Transporte y entretenimiento explican la mayor parte del aumento."

| No | Sí |
|---|---|
| "Su comportamiento financiero presenta una desviación negativa respecto a los parámetros presupuestarios." | "Este mes estás gastando más de lo planeado." |
| "Se recomienda implementar estrategias de optimización de recursos." | "Podrías reducir tus gastos en entretenimiento para acercarte a tu meta." |
| "Debes dejar de gastar en restaurantes." | "Tus gastos en restaurantes subieron 24%. Si quieres reducirlos, podrías fijar un presupuesto mensual para esta categoría." |

### Agente de IA

Se comporta como **asistente financiero**, no como vendedor: breve cuando el dato es simple, explicativo cuando hay complejidad, siempre respaldado en datos, sin juicios, sin alarmismo y con una acción concreta al final.

---

## 7. Principios de diseño

**Simplicidad · Jerarquía · Consistencia · Confianza · Acción · Progreso · Transparencia**

El objetivo final es que el usuario piense: *"Ahora entiendo mejor mi dinero"* y después *"Ahora puedo tomar mejores decisiones"*.
